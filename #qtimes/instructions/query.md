# Workflow di risposta alle domande

1. Leggi `wiki/index-wiki.md` per identificare le pagine pertinenti.
2. Leggi le pagine pertinenti e sintetizza la risposta dalla wiki.
3. Cita le pagine wiki specifiche usate.
4. Se l'informazione non è nella wiki, dichiaralo chiaramente — non inventare.
5. Se la risposta è utile per usi futuri, proponi di salvarla nella wiki.

Risposte utili possono includere: confronti tra popolazioni, tabelle PRAXIS, note di sintesi, memo decisionali.
