# Labeling Legacy Archive

## Scopo

Questa cartella raccoglie artefatti storici non canonici ma rilevanti per la ricostruzione metodologica.

## Artefatti

- `analisi_mu.db`
  - descrizione: prima base di labelizzazione storica (fase iniziale);

Gli artefatti qui dentro non sostituiscono la pipeline canonica `dati -> corpus -> 04-label/labels/wiki`.
