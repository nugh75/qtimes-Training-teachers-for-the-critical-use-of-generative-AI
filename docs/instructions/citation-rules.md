# Regole di citazione

- Ogni affermazione fattuale nella wiki deve referenziare il file sorgente.
- Formato: `(source: [filename](path/filename.md))` — ogni citazione DEVE essere un link markdown.
- **Biunivocità**: ogni tag `(source: ...)` contiene esattamente UN link. Mai raggruppare più fonti in un unico tag.
- **No abbreviazioni**: non usare `cfr.`, `e segg.`, `ecc.` Ogni fonte va citata esplicitamente con il proprio `(source: [link])`.
- Se due fonti si contraddicono, annotare la contraddizione esplicitamente.
- Se un'affermazione non ha fonte, marcarla come da verificare.
- In chat: citare le pagine wiki. Nelle pagine wiki: citare le fonti corpus.
