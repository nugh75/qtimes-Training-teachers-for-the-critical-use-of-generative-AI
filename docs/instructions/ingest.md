# Workflow di ingestione

Quando l'utente aggiunge una o più fonti in [Praxis-ql/02-corpus](../../Praxis-ql/02-corpus/) e chiede di ingerirle:

1. Leggi il documento sorgente per intero.
2. Discuti i punti chiave con l'utente **prima** di scrivere nella wiki.
3. Crea una pagina di sintesi in [Praxis-ql/01-wiki](../../Praxis-ql/01-wiki/) con il nome della fonte.
4. Crea o aggiorna le pagine PRAXIS pertinenti (sotto-temi, concetti, confronti).
5. Aggiungi `[[wiki-links]]` per collegare le nuove informazioni alle pagine esistenti.
6. Aggiorna le sintesi esistenti se la nuova fonte le rafforza, indebolisce o contraddice.
7. Aggiorna [Praxis-ql/01-wiki/00-indice/index-wiki.md](../../Praxis-ql/01-wiki/00-indice/index-wiki.md) con le pagine nuove o modificate.
8. Appendi una voce a [Praxis-ql/01-wiki/40-governance/log.md](../../Praxis-ql/01-wiki/40-governance/log.md) descrivendo cosa è cambiato.
9. Ogni affermazione fattuale deve citare la fonte corpus — vedi [docs/instructions/citation-rules.md](./citation-rules.md).

Una singola fonte può toccare 10-15 pagine wiki. È normale.

Preferire l'ingestione di una fonte alla volta, salvo richiesta esplicita di batch.
