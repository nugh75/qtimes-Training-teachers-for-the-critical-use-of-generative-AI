# Formato pagina wiki

Ogni pagina wiki deve seguire questa struttura:

```markdown
# Titolo pagina

**Summary**: Una o due frasi che descrivono la pagina.

**Sources**: Elenco dei file sorgente raw da cui la pagina attinge.

**Last updated**: Data dell'ultimo aggiornamento.

---

Contenuto principale. Titoli chiari, paragrafi brevi.

Usare [[wiki-links]] per collegare i concetti correlati.

## Pagine correlate

- [[concetto-correlato-1]]
- [[concetto-correlato-2]]
```

Metadati opzionali (tag, frontmatter) sono ammessi solo se genuinamente utili.
